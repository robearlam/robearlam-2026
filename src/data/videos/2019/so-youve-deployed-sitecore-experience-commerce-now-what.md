Presenter: Rob Earlam, Sitecore

This session covers the gap we currently have with existing XC enablement. We have lots of documentation covering how to install XC locally and also how to develop plugins, but there are some steps that need to be performed between these two actions. In this session I will cover how to setup an XC solution to follow Helix guidelines, this solution structure will contain code that needs to be published to each of the required publishing targets (XP & XC). I will then demonstrate how to use Azure Devops to create a simple CI pipeline to deploy this solution out to an Azure PaaS environment.
