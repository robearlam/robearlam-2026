In this session, Rob will show how you can build for XM Cloud using the new ASP.NET Core SDK. As part of Sitecore's effort to support more development languages and frameworks in XM Cloud, the ASP.NET Core SDK is now available as an Open Source alpha release. We will see a live demo showcasing some of the key features of the SDK. Rob will also discuss key considerations when working with a Server-Side Rendered language like this and XM Cloud.
