Sitecore serialization helps teams of developers to synchronize database changes between their individual environments.

In this video, Sitecore Technical Evangelist Rob Earlam takes you through an introduction to the new Sitecore 10 serialization tooling by showing off the new command line tooling available with Sitecore CLI as well as the new plugin Sitecore for Visual Studio.
