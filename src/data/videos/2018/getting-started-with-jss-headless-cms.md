Headless CMS architecture separates back-end content functions (such as creation, management, and storage) from front-end functions (such as presentation and delivery). There are several advantages of this approach, including:

- Improved scalability
- Easier integration with other systems
- Improved performance
- Improved security
- Greater content reuse
- Better team efficiency

In this video, Sitecore Developer Advocate Rob Earlam walks through some of the key headless developer concepts of Sitecore JavaScript Services (JSS).

JSS Is a complete SDK for JavaScript developers that enables you to build full-fledged solutions using Sitecore and modern JavaScript UI libraries and frameworks.
