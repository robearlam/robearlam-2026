Sitecore Discover is a product discovery optimization engine. It enables intelligent product search powered by AI, and can enhance experiences anywhere merchandising information is displayed. As a headless platform, it also delivers omnichannel personalization across mobile, web, email, and in-store.

And the news gets even better: The eagerly-anticipated new JavaScript SDK for Sitecore Discover has arrived!

The JavaScript SDK for Sitecore Discover is a React library, which makes it suitable for React-based applications and frameworks like Next.js. Key advantages include:

- Complete control over catalog experience design
- Flexibility in distribution of responsibilities between developers and merchandisers
- Eventing and custom component models

In part 1 of this 2-part video series, Sitecore Senior Developer Advocate Rob Earlam dives into the different implementation options for Sitecore Discover, explores the JavaScript SDK, and discusses the eventing model.
