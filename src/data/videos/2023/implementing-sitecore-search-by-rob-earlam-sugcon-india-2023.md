The Developer Relations team at Sitecore recently implemented Sitecore Search on our Developer Portal. In this session, Rob will give an overview of the project and the different learnings we achieved along the way.
Topics including:
Federated Search
Search Widgets
Search Configuration
Eventing & Analytics
React SDK
Challenges Faced

This session gives attendees a walkthrough of what working on a Search project will be like. We will walkthrough the main features of Sitecore Search and discuss some of the challenges we faced to help them with any future implementation issues they might face.

We will discuss the variety of different Index Sources that have been configured, including a walkthrough of the different configurations required to pull in a selection of diverse content locations.

Everything we will discuss is live and as the Developer Portal is Open Source, all of the code samples shown will be publicly available for any of the attendees who want to refer back to the implementation after the session has concluded.
