Accessibility is a delivery habit, not a final QA phase.

```html
<label for="email">Email</label>
<input id="email" type="email" autocomplete="email" />
```

- Use semantic elements first.
- Verify keyboard focus order.
- Test color contrast.

> "Works for me" is not a test strategy.
