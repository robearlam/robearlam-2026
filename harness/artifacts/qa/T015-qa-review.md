### AC-3: Theme Behaviour

1. AC-3.1: On first visit with no stored preference, OS `prefers-color-scheme` is applied  
   Status: Pass  
   Notes: FOUC-prevention script: `else if(!t && window.matchMedia('(prefers-color-scheme: dark)').matches){ document.documentElement.classList.add('dark') }`. No stored value causes system preference to be evaluated and applied.

2. AC-3.2: Activating the toggle switches the active theme immediately without a page reload  
   Status: Pass  
   Notes: `toggle()` calls `applyTheme(next)` (adds/removes `dark` class on `document.documentElement` synchronously), then `notifyThemeListeners()` which triggers `useSyncExternalStore` re-render. No page reload required.

3. AC-3.3: The user's toggle choice is saved to `localStorage` under a stable, named key  
   Status: Pass  
   Notes: `THEME_KEY = 'theme'` (exported constant). `setStoredTheme()` writes `'dark'` or `'light'` to `localStorage.setItem('theme', ...)`. Confirmed stable key. Covered by unit tests.

4. AC-3.4: On return visits, the stored preference is applied before page paint — no FOUC  
   Status: Pass  
   Notes: Inline `<script dangerouslySetInnerHTML>` is the first child of `<body>` in `src/app/layout.tsx`. It reads `localStorage.getItem('theme')` and conditionally applies `.classList.add('dark')` on `document.documentElement` synchronously. `suppressHydrationWarning` on `<html>` prevents React hydration mismatch warnings.

5. AC-3.5: If no value is stored, the site falls back to the OS system preference  
   Status: Pass  
   Notes: Script flow: stored `'dark'` → apply dark; stored `'light'` → no action (light is default); no stored value → check `prefers-color-scheme: dark` and apply dark if matched; no match → remains light. All paths covered.

6. AC-3.6: The `dark` class is applied to the `<html>` element when dark mode is active  
   Status: Pass  
   Notes: Both the FOUC script and `applyTheme()` target `document.documentElement` (the `<html>` element). Verified in unit tests: `applyTheme(true)` → `document.documentElement.classList.contains('dark') === true`.
