The past section is enclosed in a bordered, rounded container with `divide-y` separators — consistent with the "subtle borders" guidance in the design note.

**Responsive behavior — Pass**

All layouts use a single-column flow. Flex-wrapped metadata and link rows prevent horizontal overflow. E2E tests validate no scrolling at 375px and 1280px. Accordion triggers use `w-full` spanning the available width, satisfying the tap-friendly mobile requirement.

**Accessibility — Pass**

Semantic heading hierarchy is maintained (`<h1>` via `HeroSection`, `<h2>` via section headings, `<h3>` wrapping accordion buttons). `aria-expanded`, `aria-controls`, `role="region"`, and `aria-labelledby` are wired correctly on accordion elements. ChevronDown is `aria-hidden`. Focus styles use `focus-visible:outline` conventions. Design note requirements for accordion accessibility are fully met.

**Component/pattern alignment — Pass**

`EngagementItem` is the single shared presentational primitive used by both sections, as prescribed. `YearGroupAccordion` is the dedicated accordion wrapper with native button semantics. No new visual subsystem was introduced; the implementation extends existing site patterns.

The implementation uses identical date formatting across both sections and opts for independent multi-group toggle state. The design open questions do not require resolution before approval.
