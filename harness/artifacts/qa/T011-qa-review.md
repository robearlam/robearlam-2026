2. **No unit test for GA4 duplicate-prevention logic**  
   Severity: Low  
   Blocks approval: No  
   Notes: `GoogleAnalyticsTracker` includes route-change duplicate prevention via ref comparison. This logic is not tested in isolation. The risk is low since the pattern is simple and correct from code review.

3. **GA4 measurement ID interpolated directly into inline script string**  
   Severity: Low  
   Blocks approval: No  
   Notes: `GA_MEASUREMENT_ID` is interpolated into the `ga4-init` Script via template literal without format validation. The value originates from a server-controlled environment variable, so the risk is effectively zero. A stricter pattern would validate the GA ID format or use JSON.stringify, but this is not blocking.

4. **Tag/archive pages inherit root canonical URL**  
   Severity: Low  
   Blocks approval: No  
   Notes: Tag, year-archive, and month-archive pages do not override `alternates.canonical` in their `generateMetadata`, so they inherit the layout-level canonical pointing to the root URL. Since these pages are `noindex`, the incorrect canonical has no SEO impact.
