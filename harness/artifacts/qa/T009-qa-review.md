1. A page is available at `/videos` and presents video content as a listing page rather than redirecting or requiring dynamic route parameters.
   Status: Pass
   Notes: `src/app/videos/page.tsx` defines a server-rendered page at the `/videos` route. No redirects or dynamic parameters are used.

2. The page loads video entries from Markdown files located under `src/data/videos/YEAR/*.md` across all available year folders.
   Status: Pass
   Notes: `getAllVideos()` in `src/lib/videos/videos.ts` uses recursive directory traversal starting at `data/videos/`, discovering all `.md` files across year subdirectories (2025/, 2026/).

3. Each video source file is considered valid for listing only when it includes `title`, `videoId`, and `date` in front matter.
   Status: Pass
   Notes: `normalizeVideoFrontmatter()` validates all three fields are non-empty strings, with `date` additionally validated for YYYY-MM-DD format. Returns `null` for invalid entries.

4. The `date` field is defined in `YYYY-MM-DD` format and is used for sorting all videos in descending order so the newest item appears first.
   Status: Pass
   Notes: `sortVideosByDateDesc()` uses `localeCompare` on the ISO date strings for reliable descending sort. `isValidDateString()` enforces the format at parse time.

5. The first item in the sorted collection is rendered in a featured treatment that is visually larger than the non-featured items rendered below it.
   Status: Pass
   Notes: `VideosPageContent` destructures the first item as `featuredVideo` and passes it to `VideoCard` with `featured={true}`. The featured variant uses larger type scale (`text-2xl sm:text-3xl`) and more generous spacing (`space-y-5`) compared to standard cards (`text-lg`, `space-y-4`).

6. All remaining items after the featured video are rendered in a responsive grid layout below the featured section.
   Status: Pass
   Notes: `VideosGrid` renders remaining videos in `grid gap-8 md:grid-cols-2 xl:grid-cols-3`, providing responsive 1/2/3 column layout.

7. Each rendered video item displays its title and a human-readable publication date.
   Status: Pass
   Notes: `VideoCard` renders `formatVideoDate(video.date)` as muted metadata text and `video.title` as a heading. `formatVideoDate` uses `Intl.DateTimeFormat` for locale-aware formatting (e.g., "20 March 2026").

8. Each rendered video item includes a YouTube embed generated from `videoId`.
   Status: Pass
   Notes: `VideoCard` renders an `<iframe>` with `src="https://www.youtube.com/embed/${video.videoId}"` for every entry, both featured and standard.

9. Each embedded iframe includes a meaningful `title` attribute derived from the corresponding video title.
   Status: Pass
   Notes: `VideoCard` passes `title={video.title}` directly to the `<iframe>` element. Integration test verifies `screen.getByTitle("Newest Video")` is present.

## Design Alignment Review

**Structural alignment: Strong**

The page uses the `HeroSection` component for the header introduction, followed by `VideosPageContent` handling the featured/grid/empty hierarchy. This matches the design note's described structure of: page heading to featured region to supporting region to empty state.

**Visual/system alignment: Strong**

Typography uses `tracking-tight` headings, `muted-foreground` for metadata, and restrained spacing via Tailwind spacing utilities. No decorative backgrounds or heavy borders are introduced. The visual restraint specified in the design note is maintained.

**Responsive behaviour: Strong**

The grid uses Tailwind responsive breakpoints (`md:grid-cols-2 xl:grid-cols-3`) and image embeds use `aspect-video w-full` with `overflow-hidden` to prevent horizontal overflow. Single-column layout holds correctly on mobile.

**Accessibility: Strong**

Featured video section uses `aria-labelledby="featured-video-heading"`. Supporting grid section uses `aria-labelledby="more-videos-heading"`. Empty state uses `aria-live="polite"`. Every `<iframe>` carries `title={video.title}`. Heading hierarchy is one H1 followed by H2 labels for the two regions.

**Component/pattern alignment: Strong**

`VideoCard` implements both featured and standard variants through a single component with a `featured` prop, matching the design note's recommendation. Reusable components are placed in `src/components/videos/` and typed data logic in `src/lib/videos/` consistent with existing project conventions.

**Deviations from design note: None identified.**
