## Design Alignment Review

**Structural alignment:** The year archive page reuses the `section > header > h1/p + grid` structure from existing archive pages, fulfilling the design note's requirement for a familiar archive variant. No new page type introduced.

**Visual and system alignment:** `MonthlyArchivePanel` uses inline-flex year heading links with count spans in muted secondary text. Typography, border colours (`#E5E5E5`), and hover colour (`#B23A3A`) are consistent with the design system neutral palette and secondary accent usage. Year headings use `font-semibold` to distinguish them from month entries.

**Tag chips:** `TopTagsPanel` chip treatment uses `rounded-full border px-3 py-1 text-sm` — a restrained pill shape — with neutral surfaces (`bg-[#FAF8F4]`, `border-[#D9D4CD]`) for inactive chips and the design system primary dark-red palette (`bg-[#F7E7E4] border-[#B23A3A] text-[#7A1C1C]`) for the active state. Consistent with design system instructions for sparing primary colour use.

**Responsive behaviour:** `flex flex-wrap` tag layout handles multi-row wrapping naturally. Year groups are block-stacked with nested month lists. No horizontal overflow risk at standard breakpoints.

**Accessibility:** The corrective build adds `aria-hidden="true"` to count spans in tag chips, directly addressing the accessible-name cleanliness issue from QA-1. Year links, month links, and tag chips are standard `<Link>` elements with appropriate `href` values. Tag chips include `aria-current="page"` for active state. Focus-visible styles are present on all interactive elements. Note: count spans inside year heading links in `MonthlyArchivePanel` are not `aria-hidden`; year heading accessible names therefore include the count (e.g., "2026 (15)"). This is a minor residual gap, not a blocker.

**Active state for archive contexts:** Year and month archive pages do not pass active-year or active-month props to `BlogSidebar`, so year/month links are not highlighted when on their respective archive pages. This is consistent with the pre-T007.1 baseline and is not a regression introduced by this task. It represents a residual gap against the design note's guidance on active-state clarity in archive contexts.

**Overall alignment:** The implementation closely follows the design note's structural and visual intent. All critical design requirements are met. Residual gaps (archive active-state, year heading count spans not aria-hidden) are both pre-existing or low-severity observations.
