### Component Structure for Layout/Navigation/Footer

The Technical Architecture Document (Section 3.1: Layout Components) provides **complete component specifications:**

**Header.tsx:**
```typescript
interface HeaderProps {
  transparent?: boolean;
}
```
- Visual specs: Navigation links use Warm Gray 700 default, Dark Red on hover/active
- Font: Inter 500, 16px
- Height: 80px desktop, 64px mobile
- Child components: Navigation, MobileMenu, SkipLink

**Navigation.tsx:**
```typescript
interface NavigationProps {
  currentPath: string;
  orientation?: 'horizontal' | 'vertical';
}

interface NavItem {
  label: string;
  href: string;
}
```
- Active state: 3px border-bottom in Dark Red
- Hover transition: 200ms ease
- Links spaced with 48px (space-6)

**MobileMenu.tsx:**
```typescript
interface MobileMenuProps {
  isOpen: boolean;
  onClose: () => void;
  currentPath: string;
}
```
- Full-height overlay with Warm Gray 100 background
- Entry animation: slide from right, 300ms ease-out
- 44x44px touch target (NFR-32 compliance)
- Accessibility: Focus trap, ESC to close, aria-modal

**Footer.tsx:**
```typescript
interface FooterProps {
  socialLinks: SocialLink[];
}

interface SocialLink {
  platform: string;
  url: string;
  ariaLabel: string;
}
```
- Visual specs provided in Section 3.1
- Sections: Copyright, navigation shortcuts, social links
- Background: Rich Black (#1A1A1A)
- Text: Warm Gray 300 (#D4CEC7)

**Container.tsx:**
- Max-width wrapper with responsive padding
- Widths specified in Visual Design Section 5.2

**SkipLink.tsx:**
- WCAG 2.4.1 compliance (NFR-13)
- Visually hidden until focused
- Jumps to main content
